## 字芽 1.2

首次在 GitHub 发布。

### 内容
- 3500 个常用字，启蒙与一至六年级共 46 个学习单元，另有 100 多个主题分类
- 学字卡：楷体大字、拼音，朗读字 → 组词 → 造句，可重听、慢速播放，朗读后自动播放笔顺动画
- 部分常用字配有自然人声读音（AI 语音合成），其余使用系统离线语音
- 复习：打乱复习、按类别或年级复习
- 听音选字：家长设定题量（5–50）与难度（基础 / 进阶 / 挑战），只考学过的字，答错结束后讲解
- 成长报告、家长中心、五套皮肤（春芽 / 水墨 / 海屿 / 糖果 / 星夜）
- Mac 版支持键盘快捷键

## ZiYa 1.2

First release on GitHub. 3,500 characters in 46 units (starter to Grade 6) plus 100+ themes; character cards with read-aloud and stroke animation; review; listen-and-pick quiz; growth report; parent center; five skins; keyboard shortcuts on Mac.

- `ZiYa-macOS.dmg`: macOS 12+, universal, Developer ID signed and notarized.
- `ZiYa.ipa`: iOS / iPadOS 14.8+, development-signed; installs only on devices registered to the developer's account; signature valid until April 2027.

The app's interface and content are in Simplified Chinese.
